# C0 无触控调度协议探针

来源：已批准的可行性计划Task2/Task5；本地契约§3 SegmentRequest/SegmentResult、§4、§6 V03/V04/V08；详细设计F2/§9；AGENTS§11。本目录只补无游戏副作用沙盒，不是正式主控或跑刀路线。

## 实现选择与范围

- 已通过原生编辑器保存/读回：运行JS代码的jsCode；动态运行参数的__vars.runArgs.valueExp；zdjl.getVar/setVar的script/global作用域（证据56/58/59与原生导出）。
- 保持“父JS初始化→原生执行脚本（返回勾选，动态JSON参数）→父JS验证”串行；不在JS runAction中嵌套变量/JS动作（官方限制证据57）。
- 父创建本次随机调度标记，先清空结果/领取状态，发布active请求；子读出并立即清空自身runArgs，只接受匹配的active请求和未领取调度；先领取再写回。父仅接受本次标识、指定来源及完全匹配的无动作结果。
- 运行结果只支持沙盒SKIPPED_NO_CHANGE；不支持任何游戏触控、背包移动或VERIFIED_CHANGE。合成锚点不代表实际画面识别；随机标记是防意外旧值，不是加密鉴权。
- 缺失/畸形/标识错配/重复领取均fail-closed；失败通过原生JS抛错与pauseOnFail验证，不自动重试，不复跑片段。
- 本地Node测试只验证纯函数，不等于手机API/异常传播通过。每个手机子项另留截图，未执行不得验收。

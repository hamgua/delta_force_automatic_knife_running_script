# Git 提交筛选策略

来源：用户于 2026-10-16 要求只提交重要资料，分析调试图片和日志可忽略。

## 纳入 Git

- 主控原型、转换工具、原生 .zjs 样例、现行沙盒协议和触控观察器源码。
- 可离线运行的测试，以及它们依赖的 generated 样例和清单。
- 需求、详细设计、本地契约、已确认计划、测试计划、复核结论与后续任务。
- progress.md 保留为权威追加记录；诊断的 Markdown 结论保留，原始日志不提交。
- 北七原始线路 PDF、加密参考 .zjs（禁止执行/解密）、API 源资料快照及出处。
- 两份大坝地图原始数据 daba_all.json / daba_data.json（在 artifacts/legacy-tmp/kdtest/df/）。
- Git 配置说明和迁移汇总；完整机器级迁移清单只在本地保存。

## 仅本地保存，不提交

- 95 张编号证据图、burst 序列、旧实验的连续帧、截图和 XML 快照。
- PDF 渲染/裁剪图、浏览器缓存的 HTML/JS 包、旧临时脚本和采样目录。
- *.log 原始执行输出；旧 V1 观察器、生成 data URL 文本。
- 输入截图、原 Downloads 的非本项目 AGENTS 快照、安装包、解包目录、旧 venv。
- 完整 manifest.json、git-filter-local.json 和一次性绝对路径迁移脚本。

忽略规则针对已知调试目录，不使用全局 *.png/*.jpg 规则。以后需要的识别模板应放在
独立的 templates/ 或 assets/ 目录，正常提交，不放进被忽略的证据目录。

## 本次调整

- 从此前 949 个跟踪文件中取消 870 个调试文件的 Git 跟踪，约 1.60 GB；本地原件逐项哈希核对不变。
- 重要资料约 18 MB，其中原始线路 PDF 约 15.4 MB；新增本策略说明。
- 仅精简最新的本地迁移提交，不重写之前的两个提交，不 push，也不删除本地资料。
- 旧大提交的对象可能仍在本地 reflog 中，.git 大小不一定立即减少；没有执行 gc、reflog expire 或 prune。
- Git 克隆不包含被忽略的原图和日志；保留的复核结论不等同于可在纯 Git 克隆中查看原始证据。
- 不要为了缩小仓库把手机失败结论改成成功；急停释放仍 failing/red，C0 仍未完成。

## 检查方式

- git ls-files -ci --exclude-standard 应为空，避免“写了忽略规则但仍在跟踪”。
- git status --porcelain 应为空；本地忽略文件仍存在。
- 三组 Node 纯逻辑测试应独立于本地忽略的截图/日志运行。

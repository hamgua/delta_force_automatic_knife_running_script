## 五、与自动精灵脚本的映射

### 5.1 `脚本_跑刀主控.js` 中的结构

```js
CFG.route = 'W3'   // 选路线: E1/E2/E3/W1/W2/W3
ROUTES = {
  E1: { name, spawn, points: [{name, cards, steps:[...]}], extract, escape: {desc, steps:[]} },
  ...
}
POINTS = ROUTES[CFG.route].points   // 运行时 = 所选路线的点位表
```

- `points[].steps` = **屏内走位步骤**（`{w:滑动}`/`{c:点击}`/`{i:找图}`），必须由
  `tools/zjs2points.py` 从游戏内录制的 `.zjs` 生成，或按 README 第六节手工观察生成。
- `points[].cards` = 该点要收的房卡（日志追踪用，脚本不自动判卡）。
- `escape.steps` = 黄色逃生线的屏内路线（危险时由 `watchGlobal()` 触发，未录制则仅日志提示）。

### 5.2 路线选择建议

| 场景 | 建议路线 |
|---|---|
| 出生偏东/中南（主变电站附近） | E1 或 E2；背包小/求稳 → E3 |
| 出生偏西/西北 | W1（核心卡全）；要收益密度 → **W3** |
| 背包 15 格（露营背包） | 选 3 卡以内的短线（E3 / W3 前 2 点即收核心） |
| 背包 20 格（GA野战背包） | 全线（W1 / W2 / E2 四卡全收） |

### 5.3 房卡携带检查（开局前）
